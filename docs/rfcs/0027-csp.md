# RFC 0027 — Content-Security-Policy: parse, source matching, enforcement points

Status: implemented (CSP Level 3 core; documented bounds)
Packages: `cli` (`csp.ts` — policy model + matcher; `stylesheets.ts`,
`event-loop.ts`, `esm-runner.ts`, `script.ts`, `webfonts.ts`, `fine.ts`,
`index.ts` exports; `csp.test.ts`), `cascade` (`index.ts` — `style` attribute
predicate), `app` (`engine-runtime.ts`, `page.ts`, `browsing-context.ts` —
header capture, boot wiring, frame-src/frame-ancestors, report delivery)

## Decision

**One `CspContext` per document, consulted at every sink.** `documentCsp`
merges `Content-Security-Policy` + `-Report-Only` response headers with
`<meta http-equiv="Content-Security-Policy">` content into an ordered
policy list. A resource is allowed iff EVERY enforce-mode policy allows it
(report-only policies record violations without blocking). Meta policies
strip `frame-ancestors`/`report-uri`/`sandbox` per spec.

**The context is pure.** It evaluates and records violations; report
delivery, header capture, and ancestor bookkeeping live in the app/network
layer. `FineSession` carries the context as an incremental input (`DocCsp`)
so stylesheet and computed-style queries depend on it — a post-parse
`setCsp` correctly invalidates style outputs.

**Fetch kinds map to directives, element requests get `-elem`.**
`check(kind, url, variant?)`: `script-src-elem` governs `<script src>`
element requests (collect + dynamic insertion) while plain `script-src`
still covers the module-import graph; `style-src` covers `<link>` and
`style-src-elem` the `<style>` element; `img-src` covers `<img>` and CSS
`url()` images; `font-src` covers `@font-face` sources; `connect-src`
covers `fetch`/`XHR`/`WebSocket`; `frame-src` covers iframe navigation.

**Inline sinks are checked at the point of compilation/cascade, not by
mutating the DOM.** `checkInline(kind, {text,nonce}, "elem"|"attr")`:

- inline `<script>`/`<style>` elements → `*-src-elem` (nonce, hash, or
  `'unsafe-inline'` when no nonce/hash source suppresses it);
- `style=""` attributes → a cascade predicate gated by `style-src-attr`;
- `on*` handler attributes → `script-src-attr` checked in
  `invokeInlineHandler` before the injected compiler sees the body — a
  nonce does NOT authorise an attribute; a hash needs `'unsafe-hashes'`.

**`eval`/`Function` are gated by the runner.** `allowsEval` denies unless
the applicable script source list contains `'unsafe-eval'`; both runners
throw `EvalError` before invoking the host eval.

**Mixed content is a URL gate, applied before fetch.**
`gateSubresourceUrl` upgrades `http:` subresources to `https:` under
`upgrade-insecure-requests` (secure documents), and
`block-all-mixed-content` blocks the remainder. Callers use the gated URL
for the request, so upgrades actually hit the wire.

**`frame-ancestors` is checked on the embedded document.** `checkFrameAncestors`
matches the ancestor-origin chain (no `default-src` fallback per spec);
a refused verdict surfaces as `cspBlocked` on the page and the frame does
not continue boot.

**`report-uri` delivers via the network stack.** Violations POST a
`application/csp-report` JSON body (`{"csp-report": {...}}`) to each
endpoint, resolved against the document URL.

## Source-list matching

`'self'` (same origin; a secure document also admits `wss:`/`https:` on the
same host+port), `'none'`, `*` (any network scheme, never `data:`/`blob:`),
scheme sources (`https:`, `data:`), host sources with optional port and
`*.` wildcard — per CSP3 `*.h` covers subdomains AND the apex. Nonce and
hash (`sha256/384/512`, base64 case-sensitive digest, case-insensitive
prefix) sources; `'unsafe-inline'` is suppressed when the applicable list
carries a nonce or hash. Directive fallback runs `-elem`/`-attr` →
`-src` → `default-src`, per-directive independently.

## Bounds (honest)

- **`report-to`/`Report-To` endpoints are not implemented** — `report-uri`
  only, as specified here.
- **`strict-dynamic` parses but does not yet relax the host list** for
  trusted script propagation.
- **`sandbox`, `require-trusted-types-for`, `navigate-to`, `form-action`,
  `base-uri`, `worker-src` nuances beyond the implemented kinds** are
  parsed where the fallback chain names them but have no dedicated sink.
- **No CSP Level 3 `unsafe-allow-redirects`/path-part matching** — host
  sources ignore the URL path.
- **Hash sources cover `<script>`/`<style>` text and `style`/handler
  attributes**; `integrity` (SRI) remains separate.
- **Meta policies apply only what the spec allows**; the forbidden
  directives are stripped at parse time rather than warned.
- **`frame-ancestors` consults the ancestor ORIGIN chain** supplied by the
  browser context — a nested frame that never loads cannot lie.
- **Violation `sample` carries the inline text** (≤40 chars); source-file/
  line/column fields are not produced.
- **`blob:`/`data:` scripts/styles are not special-cased** beyond source
  matching — a `data:` `<script>` is a script-src-elem fetch and matches
  `data:` sources only.
- **`javascript:` URLs are still handled outside CSP** (navigation
  pseudo-scheme); gating them through script-src is a follow-up.
